📋 Rapport Dispositifs Médicaux

Génération de rapports Excel conformes aux exigences du Ministère de l'Industrie Pharmaceutique

Version 16.0.1.0.0

📌 Description

Ce module permet de générer des rapports mensuels Excel détaillant les mouvements de stock (entrées et sorties) des dispositifs médicaux. Le rapport est conforme au format exigé par le Ministère de l'Industrie Pharmaceutique.

💡 Cas d'usage : Chaque mois, exportez facilement un fichier Excel récapitulant tous les mouvements de vos dispositifs médicaux avec traçabilité complète par lots.

✨ Fonctionnalités

📦

Gestion des Dispositifs Médicaux

Nouveaux champs dédiés sur les produits : désignation DM, pays d'origine, certification, fabricant.

📊

Export Excel

Génération de rapports Excel formatés avec en-têtes, mise en forme et données structurées.

🔍

Traçabilité par Lots

Suivi complet avec numéros de lots, dates de fabrication et dates de péremption.

📅

Filtrage Flexible

Sélection de la période et du type de mouvement (entrées, sorties ou les deux).

⚙️ Configuration

1. Activer le suivi par lots

  • Aller dans Inventaire → Configuration → Paramètres
  • Activer Numéros de lots et numéros de série
  • Activer Dates d'expiration

2. Configurer un produit Dispositif Médical

  • Aller dans Inventaire → Dispositifs Médicaux
  • Créer ou modifier un produit
  • Cocher "Est un Dispositif Médical"
  • Renseigner les champs : désignation, pays d'origine, certification, fabricant

3. Configurer les lots

  • Aller dans Inventaire → Produits → Lots/Numéros de série
  • Renseigner la Date de Fabrication (nouveau champ)
  • Renseigner la Date d'expiration
⚠️ Important : Seuls les produits marqués comme "Dispositif Médical" apparaîtront dans le rapport.

🖨️ Générer un Rapport

  1. Aller dans Inventaire → Dispositifs Médicaux → Rapport Mensuel (Excel)
  2. Sélectionner la période (date début / date fin)
  3. Choisir le type de mouvement :
    • Entrées et Sorties
    • Entrées uniquement
    • Sorties uniquement
  4. Cliquer sur "Générer le Rapport Excel"
  5. Le fichier .xlsx se télécharge automatiquement
